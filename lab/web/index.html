Cube × Data360 Lab
Trình thử REST và SQL API

Truy vấn

Chọn API muốn gọi. Nội dung bên trái sẽ đổi theo tab.

REST dùng JSON. Tab SQL sinh ra hiển thị SQL mà Cube tạo cho query này.
Gửi SQL thật qua HTTP transport `/v1/cubesql` của Cube.
Tenant ID được ký vào JWT mẫu để thử lọc tenant. Chỉ dùng secret và dữ liệu local của lab.

Kết quả

Chạy query để xem dữ liệu.

Sẵn sàng
Chọn bài lab hoặc nhập query rồi bấm Chạy.
Raw JSON sẽ hiển thị ở đây.
SQL do Cube sinh ra sẽ hiển thị ở đây.
